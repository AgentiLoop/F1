AgentiLoop Racing F1 web-thin for Windows 10 and 11 (x64 and ARM64)

Plays the hosted game at https://f1.gokart.games in a Microsoft Edge app window: Edge's built-in Chromium
engine (WebGL, Web Audio, Xbox and other standard gamepads), no tabs or address bar. Nothing else to
install, since Edge ships with Windows. No game files are bundled, so it needs an internet connection and
always runs the latest deployed version.

1. Unzip AgentiLoopF1-web-thin-*-win.zip.
2. Double-click Install.cmd. It copies the app to %LOCALAPPDATA%\Programs\AgentiLoopF1-Web, adds
   "AgentiLoop Racing F1" to the Start menu and the desktop, and starts the game.
   (If Windows asks whether to run a downloaded file, choose Run / More info > Run anyway.)

Other ways:
  AgentiLoopF1.cmd   play straight from the unzipped folder, without installing
  Uninstall.cmd      removes the shortcuts, the app folder and its saved settings

Other URL (e.g. a local server):  set F1_WEB_URL=http://192.168.1.10:5188/  then run Install.cmd
F11 toggles full screen.
